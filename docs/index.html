Built for real workflows

🔌 Live Job Board API

Connects to Dice via MCP for real-time job search — not scraped data or cached listings. Results include salary ranges, company details, and direct application links.

MCP Connector

🎯 Contextual Fit Scoring

Claude analyzes your resume against each job's requirements and explains why it's a match — not just keyword overlap, but role-level contextual scoring.

AI-Powered

✍️ Tailored Materials

Generates role-specific cover letters and resume variants that map your experience to each position's requirements. No templates — every letter is unique.

Per-Role

🤖 Three Automation Tiers

Copilot (you drive), Autopilot (agent drafts, you approve), or Autonomous (full automation). Pick the level of control that fits your comfort.

Configurable

📊 Career Command Center

Every application saves to a Notion database with status tracking, fit scores, materials, and links. Your entire pipeline — organized, filterable, searchable.

Notion Native

🔄 Workflow Relay Pattern

5 specialized worker tools chain together: Scanner → Materials → Insight → Status → Config. Each handles one job, passing context to the next.

Quick start

Get JobRelay running in your own Notion workspace in under 5 minutes.

# Clone the repo
git clone https://github.com/nycsav/notion-career-agent.git
cd notion-career-agent

# Install dependencies
npm install

# Configure your environment
cp .env.example .env
# Add your Notion API key and workspace ID

# Build and deploy workers
npm run build
